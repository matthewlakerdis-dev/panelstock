Your register, in the browser

Excel data + clickable supporting documents

  1. Save your Excel register and allow OneDrive to finish syncing.
  2. Choose Load Excel register and select your existing .xlsx or .xlsm workbook.
  3. Use Stage, Villa, Scope, Colour or search to narrow the table.
  4. Click Links beside a row to add villa, scope and PO document URLs.
  5. Choose Save dashboard to download a JSON file with the data and your links. Store it privately in OneDrive. Next time, use Open saved dashboard.

To refresh, load the latest Excel workbook. Links you added are retained for matching ScopeEntryID and PO references. Save the dashboard again after refreshing.

Workbook structure

The workbook needs a VillaScopes-style sheet with headers ScopeEntryID, Stage, Villa, ScopeType, ScopeDescription, Colour, VillaPDFURL and ScopePDFURL. POReferences uses ScopeEntryID, POSystem and PONumber. POSystem must be Nexvia, Palm Lakes or Knotwood. An optional DocumentURL column on POReferences supplies the link for each PO.

Blank template rows are ignored. Multiple scopes per villa and multiple POs per scope remain separate. Stage and Villa are text; keep leading zeroes as text in Excel.

Loading a workbook does not run its macros or change it. This version imports a snapshot; it does not automatically sync with OneDrive, extract PDFs or update Nexvia. Document permissions still apply. No data is uploaded by the dashboard.
